# Introduction to R Shiny

Educational project and presentation about building interactive web applications with **R Shiny**.

[![Live presentation](https://img.shields.io/badge/View_Presentation-Open-20c997?style=for-the-badge)](https://vninamore.github.io/expo_shiny/)

## Contents

- Introduction to Shiny and reactive programming
- Application structure and user-interface concepts
- Examples of interactive widgets and dashboards
- Supporting R application code

## Technologies

`R` · `Shiny` · `R Markdown` · `HTML`

> GitHub Pages displays the static presentation. Running the Shiny application itself requires an R server such as ShinyApps.io.
